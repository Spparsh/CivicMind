How this works

  1. Search returns candidates — links, titles and snippets.
  2. Select up to 10 and fetch them. TinyFish extracts the page text.
  3. Read the extracted text and approve or reject it as a source.
  4. Approved sources provide provenance for the utility import preview, where records are validated and you confirm the import.

Only public pages are fetched. Local, private-network and non-web addresses are refused before any request is made. The API key stays on the server.
